AHK-free Space integration - GitHub backup mode v2

Files:
- scrcpy_audible_launcher_AHK_FREE.cs
- scrcpy-noconsole.GOOD.vbs
- INSTALL_AHK_FREE_GITHUB_BACKUP_v2.bat

Install:
1. Extract all 3 files into:
   E:\app\scrcpy-win64-v3.3.1\
2. Run:
   INSTALL_AHK_FREE_GITHUB_BACKUP_v2.bat
3. Start from the usual scrcpy_audible shortcut.

This installer does not use PowerShell and does not create local .bak files.
